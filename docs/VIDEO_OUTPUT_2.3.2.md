# 视频输出设置 2.3.2 本地候选

> 历史本地开发说明。本文的双模块操作、门禁和验收状态仅对应 2.3.2，不代表当前发行版提供剧情模块；当时的样本与验收材料保存在私有归档。

直接双击 `release/candidate/2.3.2/猫猫的剪辑小助手_2.3.2_portable.exe`。这是更新后的应用，无需CMD启动器。旧候选和正式2.0.0入口保留；不公开发布。

## 使用
1. 顶部设置 → 默认视频输出目录。浏览或填写已有目录，保存后本机记住，高光与剧情共同使用。
2. 自动默认保留原高光规则：本局任务的 `output` 文件夹。剧情最终视频也交付到同一文件夹，使用剧情名称，同名自动编号，不覆盖高光。
3. 自定义全局目录时，高光保存到 `<根目录>/<录像编号>/高光时刻`，剧情保存到 `<根目录>/<录像编号>/剧情剪辑`。无录像编号时使用任务编号。
4. 每个导出确认窗口也可“选择输出位置”，覆盖本次默认；“使用默认位置”恢复跟随全局。剧情任务已有的自定义选择保持，需点击该按钮才跟随新全局设置。
5. 完成后打开视频或输出文件夹，以实际交付记录为准。原高光源素材、质量报告及录制恢复仍在本局任务中，剧情对应记录仍在独立 `story-workspace` 中；这里只统一最终视频保存规则，不合并剪辑清单。

## 本次报错
2.3.1剧情首轮任务未建立 `story-workspace`，renderer先检查并申请存储锁，找不到该目录，早于诊断日志和Steam检查。这可在隔离目录复现。2.3.2在开始剧情录制时先创建独立目录；打开导出确认的只读检查不创建目录。

普通画面录制仍需要用户手动打开并登录Steam，以显示Dota原生玩家昵称。软件只检查Steam进程，不操作账户、不启动或登录Steam。干净画面和已完成素材直接合成继续使用原门禁。

## 验证边界
原DEM只读，原高光/剧情片段与时间保持。完整离线检查、隔离路径/防覆盖/恢复检查和界面回归由本轮记录证明；不以这些检查宣称真实Dota录制通过。匿名历史任务的只读检查可以识别六段，输出目录更改不改变录制恢复指纹。

当时的完整本机报告与阶段记录保存在私有验收归档，不随公开源码提供。
