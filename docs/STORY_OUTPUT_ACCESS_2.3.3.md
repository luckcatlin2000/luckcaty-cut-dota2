## 怎么查看

在“剧情剪辑”打开本局草稿，进入“导出剧情视频”。窗口底部的按钮常驻，不必滚到长清单末尾。

- **打开文件夹**：有完整成片时打开实际交付目录；尚无完整成片时打开本局剧情录制任务目录，未创建时打开本局任务目录。不会创建或打开空的自定义交付目录冒充成片。
- **查看已录片段**：当前方案有可用的已录片段时显示，重新核验后打开片段目录。缓存片段不是完整成片。
- **播放成片**：有已保存完整成片时显示，打开交付记录对应的MP4。
- **继续上次剧情导出**：沿用既有恢复功能，用户手动点击才继续。正常从头开始明确标为“重新录制全部片段”。

失败或取消后，软件先结束原导出，再只读核对已保存片段；保留原始错误，清除过期进度。恢复检查本身失败时另行说明，仍可打开本局目录查看内容。
