# 模块分工与发行门禁（2.5.1 已正式发布）

2.5.1 延续仅高光及三模块未正式提供的发行范围，修复持续采集等待；完整发布验证与九项附件核验已通过，以下 R3 及更早验证保留为历史记录。

## 各自独立的模块

| 模块 | 职责或开发范围 | 本次官方提供状态 |
|---|---|---|
| 高光剪辑 | 本地击杀高光、时间与机位编辑、原生采集、原声 MP4、恢复与排查包 | 此次 GitHub 发行只提供这一项 |
| WTF剪辑 | 独立任务与草稿、确定性故事、主备机位与录制交接 | 尚未正式提供；本地开发候选保留 |
| 录像分析 | 独立数据读取、事件查询、选片和原有导演方案 | 尚未正式提供；不表示本机分析程序不存在 |
| 剧情剪辑 | 独立片段创作与录制交接 | 尚未正式提供 |

WTF 与录像分析是独立模块，录像分析保留原“导演方案”。当前 WTF、剧情和录像分析三个入口统一提示“尚未正式提供”，不由本版按钮启动。本次 R3 候选只含主高光程序；R2 双 EXE 仅为内部预览，原 WTF 候选、已安装程序与用户数据保留，不因发行范围调整而删除。

## 先正式提供，再检测安装

统一状态来自 [module-catalog.json](../apps/d2-highlights-desktop/module-catalog.json)。当前 `wtf`、`story`、`analysis` 三项 `released` 均为 `false`，前端与后端分别执行门禁。本机存在程序、源码已开发或内部候选通过测试，都不能替代官方正式提供状态。

以后某模块正式提供且目录状态开放后，按钮才继续检测兼容安装；检测成功并由用户点击后才能启动。未正式提供时不进入启动流程。模块不会自动下载、安装或后台定时扫描。

高光主程序不恢复默认/WTF双方案执行。旧WTF和剧情草稿保留，重分析先备份，已有媒体与恢复数据不因界面调整而删除。

## WTF 本地开发候选的功能边界

R2 内部候选复用完整解析与确定性故事构建器，规则包括已验证临时树反制、英雄击杀链和买活后短时间再次死亡；提供英雄/类型筛选、证据、置信度、节拍和机位建议。这些能力已开发，但不随 R3 高光程序发布。

采用故事后，独立编辑主备机位、时间与英雄，保存本模块草稿；录制仍交给高光剪辑，由用户确认开始。主备机位共享场次与时间窗，备用不加入默认成片时长。镜头建议不等于自动完成电影剪辑或特效。

实现与验收见[独立WTF模块](WTF_MODULE.md)。此文说明候选设计，不代表已公开发布或所有录像均已实测。

## 共享协议，不复制录制器

模块清单采用 `maomao.module/1`，WTF 使用 `toolId=wtf`，录像分析使用 `toolId=analysis`。模块正式开放后才按点击发现兼容安装；目前三项统一保持未正式提供门禁。

普通片段继续支持d2h.timestamp-plan/1.0与1.1；携带同步主备机位的WTF方案使用1.2，明确相机、场次、主备角色与默认入片标记。交接先验证源录像身份、英雄、时间与分组一致性，在独立会话中打开高光剪辑，不覆盖用户原任务，不自动开始录制。

1.2 的每个素材有独立来源标识，同组使用共享候选身份与共同事件锚点；每组唯一主机位入片，备用不入片。主程序在恢复、编辑和保存中保留 `ImportedClip` 来源与锚点，不把合法导入当作失效普通候选。复制或新增片段使用独立来源标识，手动更换候选时清理原来源，避免后续交接误更新用户副本。

## R3 发行与历史验证边界

R3 仅面向高光主程序和三模块统一门禁。完整验证退出 0：213 项 Rust 通过、9 项外部条件测试 ignored，86 项前端测试及前端生产构建、格式和严格 Clippy 通过。单主程序生产构建及范围已核对，无模块 EXE 或模块清单，不沿用 R2 双 EXE。[2.5.0 已正式发布](https://github.com/luckcatlin2000/luckcaty-cut-dota2/releases/tag/v2.5.0)，公开下载、安装包门禁、签名/篡改拒绝及隔离无输入冷启动健康检查通过。本轮未另跑真实 DEM，也未进行新的视觉、鼠标、原生保存窗口或游戏实测。

R2 已完成独立 WTF 工作台和 1.2 交接实现。完整验证退出 0：210 项 Rust 通过、9 项外部条件测试 ignored，前端 85 项测试及前端生产构建、格式、严格 Clippy 通过；真实 DEM 默认跳过的回归另行指定样本执行，1 项通过。匿名真实录像只读读取出 54 个精彩故事、64 个机位，并将一组主备两份素材导入独立录制草稿，原 DEM 内容未变。这证明该样本的分析与方案交接，不证明全部趣味/失误规则、所有录像或游戏采集均已验收。

以上 R2 结果及双 EXE 构建、候选哈希只属内部预览历史，不代表 WTF 正式提供，也不是 R3 门禁通过记录。R1 的 196 项 Rust/74 项前端和当时界面结果同样仅作历史。R2 新界面尚未完成实机交互验收，自动浏览器检查未成功启动；未做鼠标操作或启动游戏。

## 可靠性与用户控制

原始DEM只读，分析/保存/交接不启动Steam或Dota。原生采集、编码、媒体质检、帧数进度和恢复仍由录制核心集中处理。排查ZIP不含录像或媒体，缺失和截断明确显示，不自动上传。

2.5.0 R3 保留原固定采集超时策略；2.5.1 的等待修复见 [采集等待修复说明](CAPTURE_WAIT_RECOVERY.md)。离线回归、界面检查、真实录像和用户接受分别记录；用户已授权发布 2.5.1，仅高光范围不变，不能据此开放尚未正式提供的独立模块。
