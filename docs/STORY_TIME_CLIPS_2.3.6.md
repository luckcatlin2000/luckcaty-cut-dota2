# 2.3.6 按时间添加剧情片段

> 历史本地候选说明。以下操作和测试只对应 2.3.6，不代表当前高光发行版提供剧情模块。录像样本、任务副本和原始验收记录保存在私有归档。

本次只在已有“剧情剪辑”增加时间片段表单。时间范围决定录什么，录制主角决定镜头跟谁；被击杀或打野不要求本人完成击杀。

## 打开应用

直接双击 `release/candidate/2.3.6/猫猫的剪辑小助手_2.3.6_portable.exe`，无需 CMD 启动器。

当时的候选目录带有匿名历史录像的独立任务副本。进入“剧情剪辑”后可以查看三段示例：01:35—01:53、03:38—03:59、04:17—04:34，均为火猫玩家视角，共 56 秒。三段只是该样本的方案，软件片段数量没有固定为三段；原任务副本不随源码提供。

候选使用自己目录下的 jobs 副本，原任务目录和主目录 2.3.5 应用保留。原 DEM 不复制、不改写，仍使用用户已经下载的录像。不要把候选 EXE 单独移走，否则任务目录选择会变化。

## 添加一段

1. 打开“剧情剪辑”，选择录像，进入“剧情清单”。空清单可通过“打开剧情草稿”进入。
2. 点击“按时间添加片段”。
3. 输入片段名称和游戏开始/结束时间，选择录制主角。默认玩家视角，可选择英雄跟随。
4. 点击“加入剧情清单”，保存成功后表单关闭。失败时显示原因，原清单保持。

多个片段优先使用当时的“导入剧情片段方案”一次加入。历史候选附有被击杀与打野片段的录制方案；这是录像录制方案，不能用配音 JSON 替代。该样本方案不随公开源码提供。

导入与新表单沿用已有 1—100 秒、真实事件锚点、录像范围和阵容检查。游戏时钟只转换一次。重复同一英雄、同一时间区间不会再次追加。全局“剧情主角”的原行为保留，单独新建片段的“录制主角”只作用于这次新增。

## 录制

勾选本次片段，点击“导出剧情视频”。可以一次录制全部所选片段，也可以只选一段补录。输出、普通/干净画面、原声和已有录制方式沿用旧版。
