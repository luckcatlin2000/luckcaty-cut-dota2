# 本地开发与交付目录

本仓库是剪辑助手唯一日常源码入口，apps、crates、scripts和公开docs随源码维护。

- `.local/`保存私有恢复资料、构建缓存与本机验收记录，不提交。
- `jobs/`、录像、成片、采集帧、候选EXE/安装包及签名材料不进入Git历史。
- 独立录像分析具有自己的源码和运行目录；主程序只通过版本化片段协议和模块清单衔接。
- `scripts/verify.ps1`执行离线回归；新环境先准备前端依赖和锁定Rust依赖。
- 候选单独构建并保留上一版。用户确认前不替换原入口，不推送或发布；正式发布遵循[维护者流程](MAINTAINER_RELEASE.md)。

视频项目、素材和图片归属各自项目，不混入软件源码或发布包。
