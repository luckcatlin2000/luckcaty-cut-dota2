## 修改

高光和剧情共用的录制器现在为每个自有Dota进程保留一条控制连接，从启动探测、录像跳转、录制到退出收尾复用它。慢初始化沿用原回显与解码缓冲；等待录制期间读取并丢弃无关日志。命令反馈缺失或连接异常后停止，不自动重发可能已执行的命令。握手遇到连接关闭直接报告I/O失败，不继续当作启动慢。

本轮产品逻辑只改 `crates/d2-highlights-replay-control/src/lib.rs` 与 `crates/d2-highlights-renderer/src/lib.rs`。片段时间、两个模块的独立清单、镜头/HUD命令、画质、原声、输出命名与恢复规则保持。本候选不调整Steam启动项或个人配置。
