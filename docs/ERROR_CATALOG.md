# 报错排查记录

这是猫猫的剪辑小助手的统一报错索引与案例记录。先按界面的固定编号查找；旧版没有编号时，搜索原始消息或 `os error` 数字。

## 获取排查信息

[2.5.0 正式版](https://github.com/luckcatlin2000/luckcaty-cut-dota2/releases/tag/v2.5.0) 已提供 **导出排查包**：在导出视频窗口选择保存位置，即可保存 ZIP；重新打开原任务后也可导出历史记录，不需要再次运行游戏。操作与范围见 [一键导出排查包](DIAGNOSTIC_EXPORT.md)。旧版 2.0.0 尚无此入口。

1. 查看原因与处理办法，点击“复制排查信息”。内容包括软件版本、模块、录像编号、任务、阶段、片段进度、日志目录和完整原文。
2. 用“打开文件夹”进入本局任务。高光日志在 `render/logs`；旧版剧情任务日志在 `story-workspace/render/logs`，不代表当前发行版提供剧情模块。保留对应的 `render-*.jsonl`，诊断与恢复状态在 `render/cache/<指纹>` 下。
3. 保留原录像、方案、已录素材和失败现场。文件存在不等于片段完成，以恢复检查与素材校验为准。
4. 没有证据时，根因写“待定位”，不要把启动慢、Steam、国服或路径过长等假设直接写成结论。

## 编号索引

| 编号 | 原始关键词 | 含义与下一步 |
| --- | --- | --- |
| D2H-FS-003 | `找不到指定的路径`、`os error 3` | 文件路径操作失败，核对具体操作/路径。本地历史归档有 2.3.6 长路径案例，不能把所有错误 3 归为同一原因。 |
| D2H-FS-002 | `os error 2`、`录像文件不存在` | 所需文件找不到，核对录像、工具或素材位置。 |
| D2H-FS-005 | `os error 5`、`os error 13` | 文件访问被拒绝，核对目录权限和文件占用。 |
| D2H-FS-112 | `os error 112`、`os error 28` | 写入盘空间不足，检查缓存盘和输出盘。 |
| D2H-FS-000 | 其他 `文件操作失败` | 保留具体操作、路径及系统反馈，进一步分类。 |
| D2H-STEAM-001 | `Steam 未运行` | 普通和干净画面开始录制前均需 Steam 运行，由用户手动登录；软件不代为操作。 |
| D2H-GAME-001 | `Dota 2 已在运行` | 软件拒绝接管已有客户端，由用户自行正常关闭后再导出。 |
| D2H-GAME-002 | `离线导出期间意外退出` | 自有录制游戏进程提前退出，触发原因待日志定位。 |
| D2H-CTRL-001 | `启动后未能建立离线控制连接` | 握手未确认，区分超时、协议错误、连接关闭。 |
| D2H-CTRL-054 | `VConsole`、`10054`、`connection reset` | 本机游戏控制连接断开，系统错误号本身不能说明触发原因。 |
| D2H-CTRL-000 | 其他 `回放控制失败` | 核对失败命令与反馈，不能一律归为跳转或 Steam 问题。 |
| D2H-SEEK-001 | `回放跳转未确认`、`未能读取录像当前播放位置`、`最后实际 tick None` | 没有有效位置反馈，核对目标与最近反馈。 |
| D2H-SEEK-002 | `回放跳转未确认`、`尚未稳定到达指定位置` | 已收到位置但未达到稳定条件，核对目标与观测值。 |
| D2H-CAMERA-001 | `镜头位置反馈不可识别` | 当前软件不能识别镜头响应，保留实际反馈。 |
| D2H-TOOL-001 | `找不到或无法运行` | 在全局设置核对 Dota 2、FFmpeg、FFprobe 的位置与可用性。 |
| D2H-CAPTURE-001 | `有效帧序列`、`没有生成 WAV 音轨` | 原生导出缺少完整画面或音轨，检查录制反馈与文件。 |
| D2H-MEDIA-001 | `媒体处理失败` | 也可能是原生逐帧采集等待失败，尚未进入编码；结合失败阶段、帧增长和超时原因判断，保留原切片及工具日志。 |
| D2H-PLAN-001 | `剪辑方案无效`、`任务数据失败` | 核对录像身份、时间、英雄、事件锚点和数据完整性。 |
| D2H-CANCEL-001 | `成片任务已取消`、`导出已取消` | 用户取消状态，通常不是故障；核对已保存片段后决定是否继续。 |
| D2H-EXP-000 | 尚未分类的错误 | 原文和日志必须保留，定位后新增编号及回归，不强行给出原因。 |
