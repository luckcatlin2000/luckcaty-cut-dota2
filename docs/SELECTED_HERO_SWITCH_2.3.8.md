# 2.3.8 每段自动切换录制主角

> 历史本地候选说明。以下方案、测试数量和待验状态只对应 2.3.8；录像样本、任务副本与原始验收记录不随公开源码提供。

用户要求：录制时根据每段选中的主角自动切换；本次不用启动游戏测试。

## 使用

当时的便携候选为 `release/candidate/2.3.8/猫猫的剪辑小助手_2.3.8_portable.exe`，仅在本地归档中保留。候选录制使用每段已保存的英雄和视角；火猫段选火猫、水人段选水人、蓝胖段选蓝胖。玩家视角和英雄跟随两种现有选择的含义保持，无须添加新设置。

当时的匿名历史样本八段剧情草稿随本地候选独立附带，原 2.3.7 任务、视频和根目录应用保留；草稿不随源码提供。旧镜头错误的成片不会被程序修改自动修正，后续录制由用户发起。

## 程序修改

- 每段跳转稳定后，使用该段 `viewHero` 对应的真实玩家位，先选择和聚焦，再设置已选视角类型；HUD 命令仍为原有内容。
- 播放恢复后在原有预滚期再次应用本段英雄/视角；预滚仍按原逻辑裁掉，不增加成片长度。
- 连续同英雄、切换队友英雄都逐段执行。原生 60 FPS、JPEG 100、H.264 CRF 16、游戏原声、时间定位和输出命名保持。
- 新录制管线指纹为 `d2h.capture/2.3.8-selected-hero-switch-17`，避免用旧切换逻辑的恢复缓存冒充新录制结果，不删除旧素材。

运行源码只修改 renderer 的 `src/lib.rs`。混合英雄切换、十个玩家位映射、所选视角保留、预滚内应用和控制白名单有离线回归；完整离线验证退出 0：184 项 Rust、85 项前端，格式、Clippy、技能/更新协议及生产构建通过。候选为 Windows GUI 应用，文件/产品版本 2.3.8，完整哈希以 `candidate.json` 为准。

本次没有启动 Dota 2、Steam 或候选 GUI，没有重新录制。`camera_target_verified` 继续如实保留 false；尚未确认当前客户端真实镜头效果或原问题具体根因。根目录入口只在用户验收后同步。
