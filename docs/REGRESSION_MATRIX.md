## 当前主程序的离线功能合同

每个候选都应核对适用项目，逐项结果以该候选的测试输出为准。数量随测试增长，不能为了满足旧数字移除现有覆盖。

| 范围 | 必须保持的行为 |
|---|---|
| 本地导入与解析 | 选择、拖入、按本地编号载入 DEM；原文件只读；不启动游戏 |
| 录像库 | 首次进入读取、之后手动刷新、切换目录读取；不定时轮询，不联网下载录像 |
| 10 人选角 | 显示阵容，主角改变时重建该英雄击杀高光，不只换镜头 |
| 高光编辑 | 新增、复制、删除、排序，精确时间输入，入出点和时长校验 |
| 旧草稿兼容 | 当前只执行高光；保全旧 WTF/剧情槽，重分析先备份，不恢复执行旧工作台 |
| 片段英雄与机位 | 逐段保存英雄、玩家视角或英雄跟随，默认与用户选择一致 |
| 同步素材 | 同场机位编号统一、时间窗一致；备用素材不增加默认成片时长 |
| 普通/干净画面 | 始终可见并保存；普通只隐藏回放控制，干净隐藏 HUD 与指针 |
| 导出预览 | 素材数量、片段、英雄、机位、时长与原声明确；取消预览不启动游戏 |
| 外接入口 | 先核对官方提供状态；当前 WTF、剧情与录像分析统一提示且不启动，正式开放后才检测兼容安装 |
| 功能归属 | 高光中没有默认/WTF 切换；WTF 剪辑与录像分析是独立程序，实际交付与公开发布分别记录 |
| 导入来源 | 恢复、编辑与保存保留来源和锚点；合法导入不因普通候选缺失而锁定；复制不共用可更新来源 ID |
| 异步与关闭 | 分析、保存、导出、更新互斥；旧任务不覆盖新工作区；退出等待自有进程确认关闭 |
| 缓存身份 | 核对源内容、方案、管线与媒体；损坏、缺失、方案变化不能静默复用 |
| 输出保护 | 重复导出自动编号，不覆盖已有成片与同名工件 |
| 清理保护 | 仅隔离夹具测试删除；保留 MP4、断点、诊断，拒绝链接、范围变化及未完成缓存 |

WTF 故事生成、砍树筛选、双方案工作台、剧情创作与分析包等属于旧多功能版本或独立模块范围，不再是当前高光桌面的验收入口。共享解析库保留的相关测试不代表这些功能仍在主程序中提供。

## 排查记录与一键导出的合同

| 场景 | 期望 |
|---|---|
| 采集开始及阶段切换 | `capture_wait_start` 记录目标和总帧数，共享整个片段计时，不重新计算超时预算 |
| 采集推进与停滞 | `capture_progress` 约每 5 秒节流，记录当前帧数、最后增帧时刻和停滞时长 |
| 超时、取消或其他失败 | 终态记录最后计数；诊断写失败不覆盖主错误 |
| renderer 前失败 | 导出尝试摘要保留早期失败，缺少原生录制日志时明确说明 |
| 强杀或断电 | 允许只有开始记录，不能当作成功；旧版未记录数据无法补回 |
| 当次错误及历史任务 | 都能导出当前任务已有排查信息，不要求重跑游戏 |
| 保存窗口 | 用户选择 ZIP 位置；取消不生成文件；同名文件不直接覆盖 |
| 包含范围 | 仅报告、清单、约定日志、尝试摘要、状态、诊断、质量 JSON 与方案 |
| 排除范围 | 无 DEM、图片帧、音频、视频、账户配置；不跟随链接或状态中的外部媒体路径 |
| 体积与数量 | 限量读取，超限、截断、缺失、失败写入清单与界面 |
| 桌面与预览 | 桌面可请求导出；浏览器预览明确提示不可导出 ZIP |
| 发送方式 | 保存后手动发送，不自动上传 |

详细路径和容量见 [排查包说明](DIAGNOSTIC_EXPORT.md)。原生导出的固定超时公式、采集画质、60 FPS、镜头、原声与时间窗未在本轮调整。

## 游戏实录：本轮未执行

实录需要单独取得用户授权，并在开始前说明内容与预计时长。只启动项目自有离线 Dota，记录其 PID，结束后确认该 PID 退出、TCP `29000` 不再监听；不得接管或关闭用户已有游戏。

后续受控实录应检查：

- 游戏原分辨率、60 FPS、目标时长与帧数一致，存在 H.264 画面和游戏原声音轨。
- 实际目标英雄、玩家视角/英雄跟随、普通/干净 HUD 与方案一致。
- 预滚不进入成片，编号源素材和清单对应，备用机位不追加到默认成片。
- 对黑屏、冻结、音画、时长与质量警告作真实媒体检查，按实际结果记录。
- 失败日志能反映持续慢速采集或停滞，排查 ZIP 可从原任务取得。
- 中断后检查完整片段并由用户确认复用，验证补录与合成。

离线帧数计算、控制反馈、构建成功和 UI 截图均不能替代以上实录。

- 不改写远端历史或强推；推送前审查完整 diff，保留品牌、许可证与商业使用规则。
- 公开源码与附件不混入用户 DEM、媒体、任务缓存、真实玩家信息、本机绝对路径或签名秘密。
- 只有实际完成发布才能写已上线；源码检查、候选交付和游戏验收分别记录。
