## 原生导出

只有改动 Replay Controller、renderer、时间换算、镜头命令或媒体管线时，才执行受控 Dota 2 回归。开始前告知用户，记录项目启动 PID；结束后只关闭该 PID，并确认 TCP `29000` 不再监听。

固定样片至少验证：

- 1920x1080、30 FPS。
- 目标时长与帧数一致。
- H.264 视频和游戏原声音轨存在。
- 0 黑屏、0 冻结、0 QC warning。
- Player View 对应所选英雄玩家位。
- 入点前预滚不会出现在最终成片。
- 每个机位都有独立 MP4，文件名按 `S001-A`、`S001-B` 对应。
- `素材清单.json` 中的场次、机位、英雄、时间码和文件路径一致。
- 备用机位存在于源素材目录，但不被顺序追加到默认成片。

## 发布物保护

- 候选测试期间，根目录正式 EXE 的版本和 SHA-256 必须保持不变。
- 候选文件只位于 `release\candidate\<版本>`。
- 候选包必须生成 NSIS 更新签名与 `latest.json`，且公钥、版本、下载地址和签名字段通过门禁。
- 启动检查只提示更新，不自动下载；只有用户明确点击后才能安装。
- 分析或导出进行中时，安装按钮必须不可用。
- 正式晋级后，根目录 EXE 与候选 EXE 哈希一致，正式安装包与候选安装包哈希一致。
- 上一版根目录 EXE 已出现在 `release\history`。

## GitHub 镜像

- 本地全部适用测试通过后才更新 `githubdota2`。
- 公开分支基于现有 `origin/main`，不得改写或强推覆盖远端历史。
- 公开仓库中不出现真实录像编号、玩家姓名、SteamID、本机绝对路径、任务目录、成片或内部进度文件。
- 保留公开仓库的许可证、品牌和商业使用说明。
- 移植后在公开镜像中再次运行 `scripts\verify.ps1`，并在推送前检查完整 diff。
