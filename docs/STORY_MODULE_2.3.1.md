# 剧情剪辑 2.3.1 本地候选

> 历史本地开发记录。以下功能、操作和验证仅对应当时的候选，不是当前高光发行版的功能承诺。录像样本和验收材料已匿名化，原文件保存在私有归档，不随源码提供。

本轮名称、制作计划和效果图已由用户确认；本文件说明实现与候选试用。候选尚待用户验收，正式根入口保留2.0.0，不公开发布。

## 运行

当时的本地启动入口为 `release/candidate/2.3.1/启动候选.cmd`，连接已有任务目录；候选及任务均不包含在公开源码中。原来的根目录程序继续保留，两版不要同时编辑同一局任务。

## 使用步骤

1. 点击左侧“剧情剪辑”，从录像库打开已有录像。已打开录像时，可以在“选择录像”页切换当前局。
2. 点击“导入剧情片段方案”，选择或拖入JSON/TXT文件。软件核对录像、英雄和事件定位，显示本次共N段、已选M段。当前局的方案决定片段数，没有固定六段模板。
3. 勾选需要的片段，一次加入剧情清单。重复片段跳过；重叠会提示但不自动删除。时间默认只读，点击“微调”才编辑。
4. 修改剧情名称，按剧情排序，选择玩家视角或英雄跟随，按需选择干净画面。草稿独立保存，切换模块或重启后恢复。
5. 点击“导出剧情视频”，核对片段顺序、时间、总长和输出位置。点击“开始导出剧情视频”才启动Dota 2离线录制。
6. 完成后点击“打开剧情视频”或“打开输出位置”。再次进入导出确认，会检查本局剧情的恢复记录，可以继续上次导出。

## 清单和文件位置

- 原高光保持使用 `jobs/<任务>/director/edit-plan.json` 和原导出流程。
- 剧情草稿使用 `jobs/<任务>/director/story-edit-plan.json`。
- 剧情录制、切片、恢复、诊断和默认成片在 `jobs/<任务>/story-workspace/`；默认成片位于其 `output/` 子目录，使用原录像名和重复编号。
- 选择自定义输出位置后，完整成片另存于 `<所选目录>/<录像编号>/剧情剪辑/<剧情名称>.mp4`，同名自动编号。切片和恢复文件继续留在本局独立剧情任务中。
- 成片位置记录在 `story-workspace/latest-result.json`，重启后仍可打开上次结果。

同一录像与只读分析结果可以复用；两个模块的可编辑清单、视频和恢复记录不共用。剧情导入、改时间、排序或删除不会重建原高光。首版没有跨模块复制按钮。

## 匿名历史样本

已有独立剧情草稿为六段、157秒，原高光为八段。六段是该历史样本的实际方案，不是产品限制。原始方案保存在私有验收归档，不随源码提供；已在草稿里的片段再次导入会跳过重复。

这局实体解析仍缺少部分技巧和连续走位数据，使用战斗日志回退读取击杀、施法和事件时间；软件显示该能力缺口，不把缺失信息当作已确认画面。
