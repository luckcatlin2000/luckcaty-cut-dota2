# 猫猫的剪辑小助手

面向 Windows 的本地 Dota 2 DEM 高光剪辑工具：读取录像、选择英雄、调整片段，再导出带游戏原声的 MP4。

官方仓库：[luckcatlin2000/luckcaty-cut-dota2](https://github.com/luckcatlin2000/luckcaty-cut-dota2)。**[2.5.1 已正式发布](https://github.com/luckcatlin2000/luckcaty-cut-dota2/releases/tag/v2.5.1)，修复慢速持续采集被提前终止的问题。** 安装包及现有九项附件已上传并核验；发行范围仍仅为“高光时刻”，版本说明见 [更新记录](CHANGELOG.md)。

```text
本地 DEM → 10 人英雄阵容与击杀事件 → 选择并编辑高光片段
         → 用户确认导出 → Dota 2 离线逐帧采集 → 游戏原声 MP4
```

导入、解析、选片、保存方案和导出排查包不会启动 Dota 2。只有点击“开始导出视频”或确认补录后，软件才启动自己创建的 `-insecure` 离线回放进程。它拒绝接管已运行的 Dota 2，不控制在线比赛、不注入游戏进程，也不依赖 OBS。

> **许可证提醒：源码公开不等于允许售卖。** 未经著作权人事先书面授权，禁止销售、收费分发、发布安装包、改名换皮、套壳发布或将本软件作为托管/商业产品提供。普通用户可以使用本软件剪辑、发布和变现自己的视频。

## 相比 2.0，调整了什么

主程序现在专注于高光选择、片段编辑与可靠录制。内置 WTF 导演、剧情制作、录像分析与解说工作台已迁出，原来的双方案切换、故事页、分析包导出和内容描述输入不再是主程序的使用入口。

| 调整 | 当前行为 |
|---|---|
| 高光主程序 | 保留本地 DEM 解析、10 人选角、英雄击杀高光、手动片段与精确时间编辑 |
| 外接模块 | WTF、剧情与录像分析均尚未正式提供；三个入口统一提示，当前不启动这些模块 |
| 旧任务 | 保留旧 WTF/剧情草稿与既有媒体；当前只执行高光方案，不自动恢复执行旧工作台 |
| 录像库 | 从本地录像目录列出 DEM，首次进入读取，此后手动刷新；切换目录时读取新目录 |
| 排查反馈 | 增加“导出排查包”，将错误说明与本局诊断记录保存为一个 ZIP，历史任务也可导出 |
| 导出界面 | 对齐信息与操作区，放大关键文字，使用醒目的红色诊断入口，保留技术详情与复制排查信息 |

**2.5.1 延续仅提供高光主程序的发行范围。** WTF、剧情与录像分析的正式提供状态均为未发布，当前按钮统一显示“尚未正式提供”提示，即使本机已有独立程序也不会由这些按钮启动。这是官方发行范围的限制，不表示录像分析不存在，也不删除任何已有程序或数据。

WTF 剪辑与录像分析是独立模块，高光不恢复“默认剪辑 / WTF 导演”切换。独立 WTF 已有本地开发候选及真实故事、草稿、1.2 同步方案交接实现，作为内部预览保留，不随本次主程序发布，也不由当前导航按钮启动。开发范围与历史验证见 [WTF 模块说明](docs/WTF_MODULE.md)。

主程序保留已实现的导入来源与定位元数据校验，以及 1.2 同步主备方案的兼容基础；这些代码能力不代表相应独立模块已经正式提供。旧 WTF/剧情草稿继续保全，不自动执行。

2.5.1 针对“持续出帧仍被提前终止”修正等待策略：首帧等待 120 秒、连续无新增帧 60 秒，并设宽总上限。画质、目标帧数、60 FPS 和成片速度保持。发布验证已通过，实机导出仍待验收；2.5.0 安装包保留旧固定超时策略。规则与验证见 [采集等待修复说明](docs/CAPTURE_WAIT_RECOVERY.md)。

## 保留的剪辑与录制能力

- 选择、拖入 `.dem`，或按本地录像目录中的编号加载；读取比赛信息、10 人英雄阵容和击杀事件。
- 按英雄整理连续击杀，新增、复制、删除、排序片段，调整入点、出点与击杀铺垫。
- 每段选择录制英雄、玩家视角或英雄跟随；同场备用机位保持统一编号和时间窗，不增加默认成片时长。
- 选择普通画面或干净画面。普通画面保留游戏 HUD，只隐藏回放控制模块；干净画面隐藏 HUD 和指针。
- 使用 Dota 2 原生分辨率、60 FPS、JPEG 100 采集画面和游戏原声，再由 FFmpeg 编码、合成与检查。
- 检查已保存的完整片段，由用户选择断点续录或重新录制；全部片段完整时直接继续合成。
- 沿用录像名称生成成片，重复导出自动编号，保留源素材、已有 MP4、断点与诊断记录。

录制窗口可能慢于实时播放，完成片段与镜头自动识别是两个不同状态；请查看实际素材后再确认复用。软件不自动添加文案、字幕、模型生成内容、配音、音效或外部 BGM，不引入云端生成服务，也不自动上传录像、媒体或排查包。

## 下载与使用

Windows 10/11 x64 用户可从 [2.5.1 正式 Release](https://github.com/luckcatlin2000/luckcaty-cut-dota2/releases/tag/v2.5.1) 获取安装包 `luckcaty-cut-dota2_2.5.1_x64-setup.exe`；其余配套说明、许可证、更新签名及哈希随九项附件提供。

官方安装版包含配套 FFmpeg/FFprobe，许可证与来源随包提供。独立便携 EXE 不包含媒体工具；请保留配套目录，或自行配置工具路径。Release 会提供 SHA-256 供核对。应用发现新版本时仅提示，下载和安装由用户决定。

1. 启动软件，选择、拖入 DEM，或从本地录像库载入；下载了新录像后点击“刷新”。软件不会按编号联网下载录像。
2. 在“高光时刻”选择主角，检查片段清单；调整时间、每段英雄、机位及普通/干净画面。
3. 点击“导出视频”，核对源素材数量、成片时长、文件名和游戏原声。
4. 正常退出自己打开的 Dota 2，手动登录并保持 Steam 运行，再点击“开始导出视频”。录制期间不要操作软件启动的游戏。
5. 完成后播放视频或打开成片、源素材目录。中断时保留原任务，重新打开导出窗口检查可恢复片段。

完整操作见可离线阅读的 [网页版使用说明](使用说明.html)。

## 出错后，一键导出排查包

在“导出视频”窗口点击红色 **导出排查包**，选择 ZIP 保存位置。完成后会显示路径，可点击“打开所在文件夹”。重新从“最近任务”打开原任务后，同一窗口也能导出历史记录，无需为拿日志再次运行游戏。

ZIP 包含当前排查说明、已有录制日志、早期失败或取消的尝试摘要、恢复状态和片段诊断，不包含 DEM、图片帧、音频或视频。保存完成后由用户手动发送，不自动上传。

新录制日志约每 5 秒记录帧数、目标、经过时间与停滞时长，并在超时或失败时保存最后计数。旧版没有记录的进度无法补回；缺失、截断或超限会在包内说明。详细内容与限制见 [排查包说明](docs/DIAGNOSTIC_EXPORT.md)。

## 后续怎样扩展

录制核心负责录像校验、时间与机位、采集、原声、恢复和成片。独立WTF剪辑、录像分析、剧情组织与解说工作由独立分析或创作模块承担，通过统一的版本化片段协议交接；录制器不因新增一种分析工具再复制一条采集链路。

模块状态统一来自 `module-catalog.json`，当前 `wtf`、`story`、`analysis` 的 `released` 均为 `false`，前后端分别执行门禁。以后相应模块正式提供、目录状态开放后，还需本机安装检测成功且版本兼容，用户点击才会启动；不后台定时扫描或自动安装。交接仍先校验录像、时间与英雄，最后由用户确认才进入离线录制。设计边界见 [模块设计](docs/MODULE_DESIGN.md)，接口细节见 [录制交接约定](docs/RECORDING_INTEGRATION.md)。

## 开发与仓库边界

环境要求：Windows 10/11 x64、Rust 1.89 或兼容版本、Node.js 与 npm、FFmpeg/FFprobe；仅真实画面导出需要 Steam 版 Dota 2。源码仓库不包含媒体工具二进制，请将其放入 `PATH`、设置 `FFMPEG_EXE` / `FFPROBE_EXE`，或放入被 Git 忽略的 `tools\ffmpeg\bin\`。

```powershell
cd .\apps\d2-highlights-desktop
npm ci
cd ..\..
.\scripts\verify.ps1
.\scripts\desktop-dev.ps1
```

发布者如需捆绑 FFmpeg，必须为实际二进制提供对应许可证、构建来源和源码材料。完整历史见 [CHANGELOG.md](CHANGELOG.md)，当前源码记录见 [CURRENT_STATE.md](docs/CURRENT_STATE.md)。

仓库只包含源码、锁文件、构建脚本和维护文档，不提交 DEM、成片、任务缓存、`target/`、`node_modules/`、EXE、安装包、FFmpeg 二进制、本机路径、账户配置或私有素材。本仓库及其 README、Issues、Releases 等只用于“猫猫的剪辑小助手”，不混入无关产品。
