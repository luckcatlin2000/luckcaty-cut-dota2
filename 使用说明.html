2.5.0 调整了什么

主程序现在专注于高光片段与可靠录制。原来内置的 WTF、剧情、录像分析和解说工作台迁出；高光中不再提供“默认剪辑 / WTF 导演”切换、故事页或分析包导出。

高光时刻

本次唯一正式提供范围：本地 DEM 解析、10 人选角、片段与时间编辑、玩家视角/英雄跟随、普通/干净画面、原声、60 FPS 和断点续录。

其他模块尚未正式提供

WTF、剧情与录像分析三个入口统一提示，当前不启动模块。WTF 有独立本地开发候选；录像分析保留自己的数据分析和导演方案，官方未提供不等于本机没有程序。

先核对官方提供状态，模块正式开放后才检测本机兼容安装，检测成功并由用户点击后启动。当前三项均未开放，即使已有安装也不由这些按钮启动。旧草稿、原候选与媒体保留，不自动扫描、安装或删除。

本版新增手动刷新录像库、一键排查 ZIP、采集进度与早期失败摘要；导出信息排列更整齐，关键文字更大，诊断入口使用红色强调。分析与创意模块通过统一片段协议交接，用户确认后才启动离线录制。

本轮没有启动 Dota 2 或重新进行游戏实录验收，原生逐帧导出的固定超时策略尚未修改。本版不承诺所有导出故障已经解决。

WTF、剧情与录像分析尚未正式提供

本次 GitHub 发行和 R3 候选只提供主高光程序。三个模块按钮统一显示“尚未正式提供”，前后端均有门禁，不以本机文件存在绕过。中央 module-catalog.json 中 wtf、story、analysis 的 released 当前均为 false。

已开发、已安装与正式提供是不同状态。

独立 WTF 已有 R2 本地开发候选，故事、草稿和同步交接实现继续保留；不随本次主程序发布，也不从当前按钮启动。录像分析是独立程序，“未正式提供”不表示它不存在。原候选、分析程序、草稿和媒体均不删除。

将来模块正式开放后，还需检测到兼容安装，用户点击才会启动。主程序保留来源校验和 1.2 主备同步方案基础，备用不增加默认成片时长；这些兼容能力不等于独立模块已经公开提供。旧 WTF 双模式草稿继续保全，不自动执行。

01开始前准备

  1. 2.5.0 正式发布后，从官方 GitHub Releases下载 luckcaty-cut-dota2_2.5.0_x64-setup.exe，双击安装。官方安装版带 FFmpeg / FFprobe；发布前以 Release 实际附件为准。
  2. 准备本机已有的 .dem 录像；导出游戏画面需要安装 Steam 版 Dota 2。
  3. 导出前正常退出你已经打开的 Dota 2，手动登录并保持 Steam 运行。普通与干净画面都使用相同的离线录制检查。
  4. 启动“猫猫的剪辑小助手”，检查左下角“本机能力”。Dota 2 未找到时，在右上角“设置”中选择 dota2.exe，点击“应用路径”。

便携版可运行 猫猫的剪辑小助手.exe 或下载的 portable EXE。单独的便携 EXE 不包含 FFmpeg；请保留配套的 tools\ffmpeg\bin\ffmpeg.exe 和 ffprobe.exe，或使用安装版。

先剪辑，后启动游戏。

导入、分析、选片和调整时间都不需要启动 Dota 2。点击开始导出或补录时，软件才启动自己创建的离线回放进程；不会接管你已经运行的游戏。

02导入录像，选择主角

STEP 1导入 DEM
STEP 2选择主角
STEP 3调整片段
STEP 4导出 MP4
  1. 点击左上角 导入录像，选择或拖入 .dem 文件。也可先设置“录像目录”，输入录像编号，加载目录里的对应文件。
  2. 等待本地分析完成，核对右侧 10 人英雄阵容。
  3. 进入 高光时刻，在“主角”页点击要制作高光的英雄，查看其连续击杀片段。
  4. 检查左侧片段清单，按需要保留高光、添加手动片段并调整顺序。

同一英雄相近的连续击杀会合并为片段。点击整局事件轴中的事件，可定位已采用片段或插入对应片段。录像库首次进入读取本地目录，此后点击“刷新”更新；切换目录时读取新目录，按文件落盘时间从新到旧排列。

软件不会按录像编号联网下载文件。主程序不生成 WTF 故事方案、树类候选或分析报告，也不自动添加文案、字幕、模型生成内容、BGM、配音或音效。

03调整片段，保留操作铺垫

在左侧选中片段，进入右侧“时间”页。先确定要展示的过程，再设置入点和出点；片段时长为 1–100 秒，并需位于录像范围内。

操作用途
短击杀默认高光片段。1.9.13 起，短击杀尽量保留首杀前至少 12 秒及技能起手前 6 秒；录像起点会限制可保留范围。
补足击杀铺垫用于已保存的旧短击杀方案。按新规则向前延长，保留当前片段选择和出点；不会重新加入已删除的片段。
完整交战用于走位、蹲人、瞄准和运营。默认首杀前保留 60 秒，可逐段设为 0–90 秒；末次击杀后保留 10 秒，整段最多 100 秒。
精确时间输入 HH:MM:SS.mmm，或用秒级、帧级按钮微调。±1f 按录像编辑时间轴的 30 FPS 调整；导出视频为 60 FPS。
新增、复制、排序、删除整理最终片段顺序。删除只移除方案中的片段，原 DEM 不受影响；同场同步机位的时间调整会联动。
示例：米拉娜射箭前反复调整角度。

不要只留下命中和击杀瞬间。先点击“补足击杀铺垫”，再检查时间范围；想保留更完整的准备过程，可切换“完整交战”或手动把入点向前移。

相邻完整交战片段重叠时，软件可能缩短后一段的前置时间，请以界面显示的实际范围为准。“重新分析”会先备份当前方案，再恢复当前主角的完整默认候选；它不是断点续录按钮。

04选择画面和机位

普通画面

保留游戏 HUD、小地图及原生玩家昵称，只隐藏右上角回放控制模块。使用你自己的游戏显示习惯。

干净画面

隐藏完整 HUD 和鼠标指针，适合制作更简洁的画面。只有主动选择后才启用。

  • 玩家视角：默认使用所选主角玩家本人的操作视角，适合呈现选手的观察和判断。
  • 英雄跟随：镜头跟随目标英雄，适合观察动作；它并不等同于正面特写或自由电影镜头。

素材编号如 S001-A、S001-B 表示同一场次的不同机位。A 是默认入片机位，B / C 是备用素材；备用机位不增加默认成片时长。

05导出视频

  1. 点击顶部 导出视频，核对文件名、画面模式、源素材数量、成片时长和声音。
  2. 第一次导出点击 开始导出视频。如发现已保存片段，请按下一节选择继续录制。
  3. 等待离线回放启动、录像载入、逐段录制、编码、合成和质量检查。录制期间不要操作软件启动的 Dota 2。
  4. 完成后在软件内播放，或打开成片和源素材文件夹。
2.0：减少缓存占用

新导出素材优先通过硬链接共用磁盘内容，不支持时自动复制。已有视频不会自动迁移。完成页点击“检查可清理缓存”，核对目录、文件数量和体积，再点击“确认清理原始帧缓存”。清理只删除已核对的原始 JPG/WAV，保留全部 MP4、断点和诊断记录。删除不可撤销；仍可复用 MP4，但从原始帧重新编码需要重新录制。外部编辑硬链接视频前请另存独立副本。

游戏窗口慢，不等于成片掉帧。

软件通过 Dota 2 原生逐帧输出画面和原声，再编码为 MP4。高质量逐帧录制可能慢于实时播放；请看“已保存秒数”是否持续推进，并以导出的 MP4 播放情况判断。若进度长期不动或报错，按“中断后继续录制”处理。

当前采用游戏原生分辨率、60 FPS、高质量图像输出与 MP4 编码，并进行标准视频颜色范围转换。软件不会替你更改游戏视频设置。高分辨率、长片段和更多机位会增加导出时间与磁盘占用，请保留足够空间。

声音固定为游戏原声。完成或取消后，软件会收尾并关闭本次自行启动的 Dota 2；请等待处理结束。

遇到问题，一键导出排查包

  1. 任务完成收尾后，在导出窗口点击红色 导出排查包。错误旁和窗口下方均有对应入口。
  2. 在系统保存窗口选择 ZIP 的位置。软件显示保存路径，可点击 打开所在文件夹。
  3. 自行查看包内内容，再手动发送给维护者。软件不自动上传或发送。
关闭软件后也能导出。

从“最近任务”重开原任务，再进入“导出视频”即可打包历史记录，无需重新启动游戏。取消保存不生成文件；打包失败单独提示，不替换原来的录制错误。“复制排查信息”仍可使用。

ZIP 包含当前错误说明、已有录制日志、早期失败或取消的尝试摘要、恢复状态和片段诊断，不含 DEM、图片帧、音频或视频。新录制约每 5 秒记录帧数与停滞情况；旧版没有保存的进度无法补回，缺失和截断会在包清单中说明。日志可能含本机路径和片段说明。

排查入口不等于超时修复。本版保留原有固定超时判定；需要新增记录来区分持续慢速采集和停滞。离线回归及界面检查不能代替实际游戏导出验收。

06录制中断后，从断点继续

2.0 支持检查和复用已保存的完整片段。遇到回放连接中断、取消或合成失败时，保留原任务和缓存，按下面步骤继续。

  1. 从“最近任务”打开原任务，保留中断时的剪辑方案、片段顺序、时间、机位与画面模式。
  2. 点击 导出视频，等待“正在检查已保存片段”。软件会显示已完成数量、剩余数量及第一个待录片段。
  3. 点击 打开已保存片段，抽查或查看已有 MP4，确认目标英雄与镜头正确。
  4. 选择 从第 N 段继续。软件重新检查缓存，只补录缺失或未通过检查的片段，然后按原顺序合成。
操作示例 · 共 25 段，在第 23 段前中断
22已保存且通过检查
3待补录
23首个待录片段

确认已有 22 段镜头正确后，选择 从第 23 段继续，补录第 23–25 段，再合成完整视频。

这是操作示例；实际可复用数量以当前任务检查结果为准。中途有其他无效片段时，也会补录对应片段。
看到的选项或状态应该怎样理解
镜头未确认软件没有自动识别目标英雄，不代表视频损坏。查看已有片段，确认镜头正确后，才能明确选择复用。
继续合成全部素材都已完整保存。可直接完成合成，不需要启动 Dota 2。
重新录制全部你主动决定重新生成所有片段时使用；它与继续录制是两个不同选项。
没有可继续的记录可能已更改方案或画面设置、缓存已缺失，或保存的媒体未通过检查。先核对是否打开了原任务与原方案。
保留任务文件夹，断点才有依据。

软件会核对录像内容、方案、文件哈希和媒体完整性。修改入点、出点、顺序、机位、画面模式，或录制管线变化后，不会把不匹配的旧素材直接混入新方案。旧文件会保留，但不保证任意旧版本素材都可续录。

07成片、独立切片和方案在哪里

优先使用软件中的“打开文件夹”“打开源素材”或“打开已保存片段”。安装版的数据位置由应用管理，不必手工猜路径。

文件内容与命名
完整成片<录像文件名>.mp4。再次导出自动追加 _2、_3，不覆盖已有成片。
编号源素材<成片文件名>_源素材 文件夹内有独立 MP4 与 素材清单.json，方便后期剪辑。
中断前保存的片段保存在任务的录制缓存中；通过导出窗口的“打开已保存片段”访问。还未完成合成时，完整源素材目录可能尚未生成。
剪辑方案自动保存在原任务中。旧 WTF/剧情草稿保全，但当前不执行；备份时建议保留整个任务文件夹。
排查包通过红色“导出排查包”保存为 ZIP，位置由你在保存窗口中选择；包含 report.txt、bundle.json 与已有诊断记录，不含媒体。

根目录便携版的任务通常位于：

软件所在目录\jobs\<任务编号>\
├─ output\　成片与编号源素材
├─ render\cache\　可供恢复检查的录制片段
└─ director\　剪辑方案及重新分析备份

原 DEM 保持只读。录制时可能准备经内容校验的副本供游戏载入，不会改写原录像。软件不上传你的录像或媒体文件。

08遇到问题怎么办

游戏启动后一直等待，或显示“未能建立离线控制连接”

先等待任务结束或点击取消并等待收尾。确认已经正常退出自己打开的 Dota 2，软件中配置的游戏路径正确，再重试。新版已修复启动握手与播放位置反馈的已知问题；仍失败时展开“技术详情”，保留完整错误和控制日志。

“VConsole I/O error / os error 10054”是什么意思

它表示游戏控制连接被远端关闭，不能只凭这一行判断游戏退出的具体原因。已经完整保存的切片可以保留。等本次任务收尾后，打开原方案检查保存进度，并选择继续录制；不要为重试删除整个任务文件夹。

只有导出时的游戏窗口很卡

原生逐帧录制不一定实时播放，干净画面也一样。只要已保存秒数继续增加，就仍在产出画面；完成后播放 MP4 检查。若成片也有卡顿，反馈具体片段编号和时间点。

出现“原生逐帧导出超时，需要若干帧，只得到若干帧”

表示软件在既有等待时限内没有收齐目标帧数，发生在画面采集阶段。单个最终计数无法区分采集较慢还是已经停滞，也不能据此认定显卡不支持。保留原任务，导出排查包；本版增加定位记录，没有修改固定超时策略。

颜色或清晰度仍不理想

先核对软件版本，并保留你平时使用的游戏视频设置。此版沿用原生分辨率、高质量编码和标准颜色转换。录制缓存与生成它的设置绑定；如果希望按新设置重新制作旧素材，请明确选择“重新录制全部”。

找不到 Dota 2、FFmpeg 或 FFprobe

Dota 2：进入设置，浏览选择正确的 dota2.exe 后应用路径。FFmpeg / FFprobe：安装版重新运行官方安装包；便携版检查配套工具目录。分析和时间编辑可在未找到游戏时继续使用。

录像编号加载失败，或分析后没有所需片段

确认所选录像目录里已有 <编号>.dem；输入编号不会从网络下载录像。新文件未列出时点击录像库“刷新”，再核对所选主角。需要恢复完整击杀候选时可用“重新分析”，它会备份并重建当前方案；精剪后请谨慎选择。

镜头正确，却显示“镜头未确认”

这是自动识别状态，不是你的人工检查结论。2.0 已把媒体完成与自动镜头识别分开；查看视频并确认正确后，可以通过“从第 N 段继续”复用通过检查的素材。

09更新与反馈
